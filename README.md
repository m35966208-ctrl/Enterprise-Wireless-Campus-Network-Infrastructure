# Enterprise Wireless Network Simulation

## Project Overview
A secure and scalable Enterprise Wireless Network designed and simulated using Cisco Packet Tracer.

## Topology
![Network Topology](topology.png)

## Key Technical Features
- **Wireless Controller:** Configured WLC and APs with WPA2/WPA3 and multiple SSIDs.
- **Layer 2/3 Segmentation:** VLANs, Trunking, and Inter-VLAN Routing to isolate Guest and Corporate traffic.
- **Routing & Core Services:** OSPF dynamic routing, DHCP for dynamic IP assignment, and NAT for internet access.
- **Security:** Access Control Lists (ACLs) to restrict unauthorized subnet access.

## How to Run
1. Download `wireless_project.pkt`.
2. Open the file in **Cisco Packet Tracer**.
